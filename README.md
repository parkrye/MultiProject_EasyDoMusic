# EasyDoMusic



MIDI 연주 · 작곡 앱. Android 앱과 Windows PC 프로그램으로 같은 기능을 씀. 인터넷 없이 앱 안 사운드폰트로 소리를 냄. EasyDo 시리즈.



## 다운로드



최신 버전 0.1.2 — [Releases](https://github.com/parkrye/MultiProject_EasyDoMusic/releases)



- Android: `EasyDoMusic-<버전>.apk` (Android 10 이상)

- Windows: `EasyDoMusic-<버전>.exe` 또는 `.msi`



## 기능



| 도구 | 내용 |

|---|---|

| 건반 | 멀티터치, 미끄러뜨리면 음 이동, 누른 높이로 세기, 옥타브 이동, 건반 크기, 서스테인, 건반으로 드럼 세트 연주 |

| 드럼 패드 | GM 드럼 4×4(크래시 · 라이드 · 하이햇 · 탐 · 킥 · 스네어 등), 가운데를 칠수록 셈, 드럼 세트 선택 |

| 코드 | 근음 12개 × 메이저 · 마이너 · 7 · maj7 · m7 · sus4 · dim · aug, 6줄을 손가락으로 쓸어 기타처럼 스트럼(빠를수록 셈) |

| 악기 | GM 128종 · 드럼 세트, 악기 최대 3개 겹치기(레이어별 음량) |

| 소리 | SF2 사운드폰트 신디사이저: 필터 · 모듈레이션 · 비브라토 · 리버브 · 코러스 |

| 작곡 | 피아노롤: 트랙별 악기 · 음량 · 팬 · 음소거 · 솔로, 노트 찍기 · 이동 · 길이 · 세기, 끊기 · 잇기 · 박자 맞춤 · 옥타브, 복사 · 붙여넣기, 되돌리기, 구간 반복 · 메트로놈. PC는 마우스 · 단축키, 휴대폰은 가로 화면 터치(두 손가락 확대 · 스크롤) |

| 연주 녹음 | 연주 화면(건반 · 패드 · 코드) 연주를 고른 트랙에 노트로 받아 적기, 예비 박 0~2마디, 녹음 후 박자 맞춤(1/8 · 1/16 · 셋잇단), 녹음 한 번 = 되돌리기 한 번 |

| 곡 파일 | 자동 저장 · 곡 목록 · 사본, `.mid` 내보내기 · 가져오기(형식 0 · 1), WAV 내보내기(재생과 같은 소리) |
| 보컬 | 보컬 트랙: 노트마다 한글 가사 한 글자, 앱 안 음성 합성(여성 · 남성)으로 노래. 가사 입력 창에서 글자를 노트 순서대로 붙임, `.mid`에 가사 이벤트로 저장. 소리는 알아들을 수 있는 기계 목소리 |

| 설정 | 화면 테마(시스템 · 밝게 · 어둡게), 곡 전체 · 설정 백업/복원(zip), 앱 정보 · 오픈소스 라이선스 |

| PC 키보드 | 건반: 아랫줄 `Z`~`/` · 윗줄 `Q`~`P`, `Space` 서스테인, `←` `→` 옥타브 / 드럼 패드: `1234` `QWER` `ASDF` `ZXCV` / 코드: `1`~`6` 줄 |
